당신은 Spring Boot 백엔드 프로젝트를 리뷰하는 시니어 개발자입니다.

현재 Git Diff를 분석하여 실제 사내 코드 리뷰에 제출할 수준의 Pull Request 문서를 작성해주세요.

다음 원칙을 반드시 지켜주세요.

* 파일 변경 내역을 단순 나열하지 마세요.
* 코드 내용을 그대로 설명하지 마세요.
* 변경의 목적과 의도를 중심으로 작성하세요.
* 왜 이 변경이 필요했는지 설명하세요.
* 어떤 문제를 해결하는지 설명하세요.
* 설계 결정과 트레이드오프가 있다면 함께 설명하세요.
* 리뷰어가 빠르게 이해할 수 있도록 핵심만 간결하게 정리하세요.
* Markdown 형식으로 작성하세요.

다음 구조를 사용하세요.

개요

이번 변경의 목적과 배경을 설명합니다.

주요 변경사항

관심사별로 변경사항을 그룹화하여 설명합니다.

예시)

* JWT 인증 처리
* Security 설정
* 예외 처리
* 테스트 코드

보안 고려사항

인증/인가 처리 방식과 관련된 설계 내용을 설명합니다.

테스트

추가 또는 변경된 테스트 시나리오를 정리합니다.

리뷰 포인트

리뷰어가 집중해서 봐야 할 내용을 정리합니다.

추가 프로젝트 컨텍스트:

* Spring Boot 3.x
* Stateless JWT 인증 방식 사용
* OncePerRequestFilter 기반 JwtAuthenticationFilter 사용
* 인증 실패 시 AuthenticationEntryPoint를 통해 JSON 응답 반환
* 회원가입 및 로그인 API는 permitAll 정책 사용
* SecurityFilterChain 기반 인증 구성
* JWT 인증 통합 테스트 추가

추가된 테스트 시나리오:

* 토큰 없음 → 401
* 잘못된 토큰 → 401
* Bearer Prefix 없음 → 401
* 유효한 토큰 → 200
* permitAll API 접근 가능 여부 검증

최종 결과는 실제 PR 본문으로 바로 사용할 수 있는 수준으로 작성해주세요.
